Commands

- `npm install` - install dependencies
- `npm run dev` - start the dev server
- `npm test` - the whole suite
- `npx vitest run tests/home.test.ts` - one test file
- `npm run lint` - lint the code
- `npm run build` - production build

Rules

- Dependencies are added in `package.json`. Do not add one without
  asking
- Tasks are tracked as GitHub issues. Work on one issue at a time and do not
  start the next one without asking.
- Read an issue's acceptance criteria before starting work and before closing
  it.
- Commit regularly.

Documents

- `_docs/process.md` - how work is organized
- `_docs/tasks.md` - archived task backlog; GitHub issues are the active source
  of work
- Before writing tests, read `_docs/testing-guidelines.md`
- For anything touching the UI, read `_docs/design-system.md`
- `_docs/api.md` - describes what the API should look like
