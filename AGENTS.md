Commands

- `npm install` - install dependencies
- `npm run dev` - start the dev server
- `npm test` - the whole suite
- `npx vitest run tests/home.test.ts` - one test file
- `npm run lint` - lint the code
- `npm run build` - production build

Rules

- Dependencies are added in `package.json`. Do not add one without
  asking
- Tasks are listed in `_docs/tasks.md`. Work on one task at a time and
  do not start the next one without asking
